# PetLog

პირადი სივრცე შინაური ცხოველის ჯანმრთელობის ინფორმაციისა და დაგეგმილი ზრუნვისთვის. ინტერფეისი აგებულია React-ით, TypeScript-ითა და Tailwind CSS-ით; მონაცემები ინახება Node.js/SQLite სერვერზე.

## გაშვება

საჭიროა Node.js 24 ან უფრო ახალი ვერსია და npm.

macOS-ზე დიზაინის გასახსნელად ორჯერ დააჭირეთ [PetLog.command](./PetLog.command)-ს. თუ აპი უკვე გაშვებულია, უბრალოდ გაიხსნება ბრაუზერში; სხვა შემთხვევაში ჩაირთვება სერვერიც. სერვერის გაშვებისას გახსნილი ტერმინალის ფანჯარა დატოვეთ ღია. დემოში ცვლილებები პირად მონაცემებს არ ცვლის; საკუთარ ანგარიშზე გადასასვლელად გამოიყენეთ „დემოდან გასვლა“.

```bash
npm install
npm run build
npm start
```

გახსენით `http://127.0.0.1:4173`. `index.html`-ის პირდაპირ გახსნა საკმარისი არ არის: ანგარიშსა და მონაცემებს სერვერი ემსახურება. `PORT` ცვლის პორტს, `PETLOG_DATA_DIR` — მონაცემთა საქაღალდეს. განვითარებისას ცალკე ტერმინალებში გაუშვით `npm run server` და `npm run dev`.

`npm run typecheck` ამოწმებს ტიპებს, `npm run build` კი ამოწმებს ტიპებს და ქმნის გასაშვებ `dist/` საქაღალდეს.

## ფუნქციები

- პროფილი: დაბადების თარიღი, მიკროჩიპი, სტერილიზაცია, ალერგიები, მნიშვნელოვანი მდგომარეობები და ფოტო.
- ვეტერინარისა და გადაუდებელი კონტაქტის ბარათი ტელეფონის მოქმედებით.
- საძიებო სამედიცინო ისტორია, სურათის სახით ატვირთული დოკუმენტები და წონის ისტორია.
- თარიღიანი ზრუნვის გეგმა განმეორებითობით: შესრულების მონიშვნისას იქმნება შემდეგი მოვლენა. შეხსენებები ჩანს აპში; ფონური push, SMS ან ელფოსტის შეტყობინებები არ იგზავნება.
- პარამეტრებში შესაძლებელია JSON სარეზერვო ასლის ჩამოტვირთვა და აღდგენა, მათ შორის წინა ვერსიის მონაცემებისა და ვიდეოების. ძველი დღიურის, ადგილებისა და მოგონებების მონაცემები ბაზაში და ექსპორტში შენარჩუნებულია, თუმცა ახალი ინტერფეისიდან ამოღებულია.
- მთავარი ეკრანიდან სწრაფად ემატება სამედიცინო ჩანაწერი, წონის გაზომვა და შეხსენება. `⌘K` / `Ctrl+K` ხსნის გვერდებისა და მოქმედებების ძიებას.
- დემო რეჟიმი ხელმისაწვდომია შესვლის ეკრანიდან ან `http://127.0.0.1:4173/#demo/overview` მისამართზე. მონაცემები მხოლოდ მიმდინარე გვერდის მეხსიერებაში იცვლება; დემო ანგარიშის API-ს არ მიმართავს.

## მონაცემები და განთავსება

ანგარიშები და ჩანაწერები ინახება `data/petlog.sqlite`-ში, ვიდეოები — `data/media/`-ში. ბაზის სარეზერვო ასლის შექმნისას გამოიყენეთ SQLite-ის თანმიმდევრული backup პროცედურა, გაითვალისწინეთ WAL და შეინახეთ მედიის საქაღალდეც. პაროლები დაცულია scrypt ჰეშით; სესიის cookie არის HttpOnly და SameSite=Strict. პაროლის ავტომატური აღდგენა ამჟამად არ არის დამატებული.

HTTPS reverse proxy-ის უკან გაშვებისას მიუთითეთ `PETLOG_SECURE_COOKIES=1` და შეზღუდეთ მონაცემების საქაღალდეზე წვდომა. სერვერი უსმენს მხოლოდ `127.0.0.1`-ზე. მრავალსერვერიანი განთავსება და სარეზერვო ასლების ავტომატიზაცია დამატებით ინფრასტრუქტურას მოითხოვს.

ძველი ბრაუზერის მონაცემები ავტომატურად ხელმისაწვდომია მხოლოდ იმავე ბრაუზერსა და origin-ზე. `file://`-დან `http://`-ზე გადასვლისას გამოიყენეთ ძველი ვერსიიდან ექსპორტირებული JSON ასლი; მისი აღდგენა შესაძლებელია საწყისი პროფილის ეკრანიდანაც. საწყისი ძაღლის გამოსახულება უცვლელია.
